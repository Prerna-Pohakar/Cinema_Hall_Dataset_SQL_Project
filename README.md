# Cinema_Hall_Dataset_SQL_Project

inema Hall Management System – SQL Project
📌 Project Overview

This project is a Cinema Hall Management System built using MySQL, designed to practice and demonstrate SQL skills from basic to advanced level.
It simulates real-world cinema operations such as movies, customers, bookings, ticket sales, and revenue analysis through structured SQL queries.

🗂️ Database Structure

The project is based on three main tables:

Movies – movie details like name, category, rating, duration, and release date

Customers – customer information such as name, age, and gender

Bookings – booking records including tickets, cost, date, and time
